Online Computer Store – Web Term Project
Project Description:

The Online Computer Store is a full-stack web-based application that allows users to browse, search, and purchase computer-related products such as laptops, desktops, graphic cards, and memory components. Users can register, log in, add products to a shopping cart, and place orders.

This project is built using:

HTML5

CSS / Bootstrap

JavaScript

PHP

MySQL

Setup Instructions:

Follow the steps below to run the project on your local machine:

Install XAMPP or any local server that supports PHP and MySQL.

Download or clone this GitHub repository.

Move the project folder into the htdocs directory inside your XAMPP folder.

Open phpMyAdmin and create a new database.

Import the provided .sql file into the database.

Open the config.php file and update:

Database name

Username

Password

Start Apache and MySQL from XAMPP.

Open your browser and go to:

http://localhost/your-project-folder-name

The sql file is in the db folder.
